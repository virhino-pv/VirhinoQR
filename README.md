# QR Studio (working name)

An original, full-featured QR code generator: live client-side rendering, rich design options, honest
instant downloads (PNG/SVG/PDF/EPS), scan verification, bulk generation, and an optional dynamic-QR tier
with analytics and an API.

**Status:** investigation & documentation phase complete — development not started (awaiting approval).
